## Overview
Application to track and eventually beat your gaming backlog!
This project is for me to practice SQL and backend development,
as well as maybe beat my own backlog of games. It uses Python
and SQLite as of yet.

## Main features to add:
- Create and view backlog
- Give games a status: completed/playing/not playing/dropped
- Give games a rating and review
- Get recommended games
